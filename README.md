## Introduction

COMP304 explored Android app development using Kotlin. This course covered Android fundamentals, user interface design, data storage, networking, and advanced mobile app features.

## Project Overview

### Midterm Project
For the midterm project, we developed an **Android App in Kotlin** that demonstrated knowledge of activity lifecycle, intents, user interfaces, and basic data persistence techniques.

### Assignments

1. **Assignment 1:** Simple Android UI
   - Created a basic Android app with a user interface following material design guidelines.
2. **Assignment 2:** Intents and Activity Lifecycle
   - Built an app demonstrating inter-activity communication and lifecycle management.
3. **Assignment 3:** Data Persistence
   - Developed an app with SQLite database integration to store and retrieve data.

## Technologies Used

- Kotlin
- Android Studio
- SQLite

## How to Run

1. Clone the repository: `git clone <repo-url>`
2. Open the project in Android Studio.
3. Build and run the app on an emulator or physical device.
